# Grading Rubric

## 1. Team Score (10 Points Total)

Evaluates overall application quality, tech stack compliance, and system integration. Applies equally to all members of the project team.

| Category | Description | Points |
| :--- | :--- | :---: |
| **Correctness (Approved Tech Stack)** | • Built strictly using the approved course technology stack <br>(`express`, `express-handlebars`, `typeorm`, `mysql2`, `express-validator`, `multer`, `jsonwebtoken`, `cookie-parser`).<br>• Follows standard architecture patterns taught in class.<br>• Full compliance with the AI Academic Integrity policy (zero AI-generated code). | **5 pts** |
| **Completeness (System Integration)** | • The application is fully integrated into a cohesive web app.<br>• All individual team member sections/pages function together as intended.<br>• Site-wide navigation and shared layouts (`main.handlebars`) function seamlessly without crashes. | **5 pts** |

---

## 2. Individual Score (15 Points Total)

Evaluates each student's live demonstration and technical defense during the **Mock Client Meeting** with the **IT Specialist**.

| Category | Description | Points |
| :--- | :--- | :---: |
| **UI Success Cases & Smooth Run-Through** | • Demonstrates a smooth, user-friendly live walkthrough of their assigned page.<br>• Proves their section succeeds and operates as intended in a clean UI environment. | **5 pts** |
| **Error Handling & Edge Cases Demo** | • Explicitly demonstrates how their page handles bad/invalid user input.<br>• Triggers `express-validator` feedback messages and shows graceful UI error states. | **5 pts** |
| **Technical Defense & Communicating Understanding** | • Clearly articulates their backend code (Express route handlers, TypeORM entity definition, validation rules).<br>• Confidently answers technical Q&A from the IT Specialist regarding their implementation. | **5 pts** |

---

## 3. Peer evaluation (15 Points Total)
Teams will participate in peer evaluations on how well teammates:
- understood the content,
- communication with other team members,
- teamwork (willingness to complete tasks in a timely manner)
- and overall contribution.

1. The peer evaluation mark is weighted by the marks achieved above in the team and individual sections
2. Marks are deducted for not following the peer evaluation instructions (-1 mark each)
3. Failure to complete the peer evaluation (-6 marks)
